The Ceria Eats catering website was developed using the Laravel 12 framework and MySQL database to improve service efficiency and professionalism. SEAFOOD NUSANTARA

Project Brief

The development of the Seafood Nusantara online ordering application using the Laravel 12 framework aims to improve efficiency and coordination in restaurant operations. FAQ Module (Internship Project)

Project Brief

The development of the FAQ module in the web and mobile-based Customer Relationship Management (CRM) application aims to improve the efficiency and quality of PT Kreasi Boga Primatama's services. This module is designed to make it easier for the PIC (Person in Charge) to manage categories, subcategories and descriptions of answers to Frequently Asked Questions (FAQ) in a structured manner, while making it easier for clients and employees to access the information they need quickly and easily.
